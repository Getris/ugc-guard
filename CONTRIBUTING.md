# Contributing

Thank you for helping improve Zooplio UGC Guard.

1. Fork the repository and create a focused branch.
2. Add or update tests for behavioral changes.
3. Run `npm test` before opening a pull request.
4. Keep public APIs documented and backward-compatible where practical.
5. Do not submit real personal data, secrets, malware, or unsafe proof-of-concept payloads.

Bug reports should include the package version, Node.js version, minimal reproduction, expected result, and actual result.
