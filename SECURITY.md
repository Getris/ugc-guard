# Security Policy

## Supported versions

Security fixes are currently provided for the latest released minor version.

## Reporting a vulnerability

Please do not open a public issue for suspected vulnerabilities. Use GitHub's private vulnerability reporting feature for this repository. Include a concise description, reproduction steps, affected versions, and any suggested mitigation.

This package is a defensive helper and does not replace output encoding, framework security controls, authentication, authorization, rate limiting, malware scanning, or professional security review.
